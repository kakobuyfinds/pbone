What to check before ordering

  1. Confirm the exact variant. Open the source listing and match the item, color and size you want. Save the listing link and the selected option together so you can compare them later.
  2. Use measurements. For sneakers, check which length the seller’s chart refers to. For clothing, compare the listed measurements with a garment you own and measure both the same way.
  3. Review quality-control photos. If your agent provides QC photos, look at the received item’s labels, stitching, closures and any measurements you requested. Check the return window before approving shipment.
  4. Estimate the delivered total. Add the item price, domestic delivery, applicable agent or payment fees, international shipping and any import charges you expect. Use a shipping quote for your destination and confirm whether the route uses actual or volumetric weight.

KakoBuy spreadsheet FAQ

What is a KakoBuy spreadsheet?

A KakoBuy spreadsheet is a directory used to shortlist products before shopping through an agent. The listings on this page come from HipoBuyFind, and both main buttons open its catalog.

Can I use a HipoBuyFind listing with KakoBuy?

If the listing provides an original marketplace URL, copy it and check whether KakoBuy accepts that URL and displays your chosen variant. The item ID shown in this catalog identifies the HipoBuyFind listing.

Why might the order cost more than the displayed price?

A different variant can have a different price. Delivery, currency conversion, agent fees and import charges can also affect the total. Confirm the current item price and get a shipping estimate before placing an order.
